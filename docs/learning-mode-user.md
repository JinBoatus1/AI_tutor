# Learning Mode — 用户使用指南

面向 **最终用户**：如何操作界面、理解页码与对话。技术细节见 [learning-mode-dev.md](./learning-mode-dev.md)。

**English:** [learning-mode-user-en.md](./learning-mode-user-en.md)

---

## 一、界面总览

Learning Mode 通常分为三块：

| 区域 | 作用 |
|------|------|
| **左侧** | **Learning progress**：教材章节目录树 + 学习进度（已学 / 未学） |
| **中间** | **教材面板**：当前匹配章节的书页预览、翻页、隐藏 |
| **右侧** | **对话**：提问、看 AI 回复、上传图片或 PDF、截图等 |

顶部导航可切换到 Home、Auto Grader、My profile 等；Learning Mode 为当前学习会话主界面。

## 二、左侧：Learning progress

### 2.1 是什么

- 显示当前教材（如 FCOS）的 **章 → 节** 树状结构。
- 每项旁括号里的数字是 **书本印刷页码**（与教材目录一致），例如 `(pp. 145–160)`、`(p. 7)`。

### 2.2 怎么用

1. **绿点 / 空心圆**  
   - **实心绿点**：已标记为「已学」。  
   - **空心圆**：未学。  
   - 点击圆点可切换该条（或整章带子节时批量切换）的已学状态。  
   - 进度会尽量与账号同步（未登录时主要保存在本机）。

2. **点击带页码的节标题**  
   - 若该节在目录里有页码范围，点击标题会在 **中间教材面板** 打开对应书页的预览（多页时可翻页）。  
   - 便于对照正文，无需先在聊天里输入章节号。

3. **Expand all / Collapse all**  
   - 一键展开或收起整棵树，方便浏览长目录。

4. **收起侧栏**  
   - 可用侧栏边缘的收起按钮把 Learning progress 收起来，给中间和右侧更多空间；需要时再展开。

## 三、中间：教材面板

### 3.1 顶栏信息

- **Textbook: …**  
  当前匹配的章节或主题名称（与目录树中的标题对应）。

- **Pages …–…**  
  显示的是 **书本标准页码区间**（与左侧树括号内一致），不是 PDF 文件内部的物理页序号。

### 3.2 翻页条（Prev / Next）

- **「Page x of y」** 表示：在当前这次加载的 **书页图片序列** 里，第几张图（共几张）。  
- 它与顶栏的 **书本页码** 含义不同：顶栏是教材印刷页；这里是「本段预览里的第几页图」。  
- 若一段跨多页，用 Prev/Next 逐页查看即可。

### 3.3 Hide

- 隐藏整块教材面板，右侧对话仍可继续使用。  
- 需要看正文时，可用对话区域提供的入口再次 **Show textbook sidebar**（若当前有书页内容）。

### 3.4 点击图片

- 部分预览支持点击放大（lightbox），便于看清公式与插图。

## 四、右侧：对话区

### 4.1 能做什么

- 用自然语言 **问数学问题**、要解释、要步骤等。  
- 系统会尽量结合当前教材目录与匹配到的书页上下文回答。  
- 支持 **图片**、**PDF 附件**（有大小限制）、以及 **截图**（浏览器允许时）。

### 4.2 与左侧的配合

- 在聊天里提到章节、小节号（如 `5.1`、`Chapter 11`）有助于对齐教材。  
- 也可先在左侧 **点节标题打开书页**，再在右侧针对当前页内容提问。

### 4.3 重置对话

- **「I already fully understand — Start a new question」**  
  用于清空当前会话状态、重新开始，适合换主题或换题。

### 4.4 简短回答

- 对「什么是 xxx」这类很短的定义问题，系统可能只回复 **一句话**；若你始终得到很长、带很多步骤的回复，可向项目维护者反馈（可能与线上版本或账号配置有关）。

## 五、常见流程示例

### 流程 A：按目录学某一节

1. 在左侧树中找到目标节（看括号页码）。  
2. 点击该节标题 → 中间出现书页预览。  
3. 在右侧输入具体问题（例如某定理、某步推导）。  
4. 需要标记掌握情况时，点击左侧圆点更新进度。

### 流程 B：直接提问，由系统匹配章节

1. 在右侧描述问题或贴上题目图。  
2. 若匹配到章节，中间顶栏会更新 **Textbook** 与 **Pages（书本页码）**，并可能加载对应书页。  
3. 结合 Prev/Next 浏览本段所有预览页。

## 六、登录与数据

- **未登录**：通常仍可使用 Learning Mode；学习进度等可能主要保存在本机。  
- **登录后**：聊天历史、进度同步等能力取决于服务配置（详见维护文档或 `docs/firebase.md`）。
